A helper that reads the variable its caller names (`setting(name)`, `os.environ[name]`, `env::var(name)`,
`process.env[name]`) is completed by what each caller hands it, as a path's parameter is. `saveReport` calls
`keep("REPORT", …)` and `saveLog` calls `keep("LOG", …)`: they were drawn writing into one place named by the call
(`Disk(setting(name))`, in Rust a place with no name), apart from the file `showReport` reads back. Each now writes the
file its variable names, `Disk({$REPORT})` and `Disk({$LOG})`, and what `saveReport` writes is the box `showReport`
reads. A default goes with the variable: `os.environ.get(name, "")`, `env::var(name).unwrap_or(String::new())` and
`process.env[name] ?? ""` handed `"REPORT"` are `{$REPORT}` alone, as the same lookup written with `"REPORT"` is.
A name no code says still names no variable.
