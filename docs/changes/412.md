them. This merge is now made by the viewer's model (`viewer/plan.js`, `siblings`) as part of the picture it hands the page,
so `engine/tests/plans.rs` asks it of every route and every overview of its programs, for every set of open boxes: every
line of the picture has both its ends among its boxes, a call included, and a box joins only siblings that draw the same
lines, calls among them. What a fault like #411's breaks is found by `cargo test`, not first by `walk` before a promotion.
Nothing in the picture changes; the test's output shows it. With the fix of #411 taken out of the model again, on
`engine/tests/plans/siblings-call`:
