In Rust, `Html(text).write(out)` and `let page = Html(text); page.write(out)` were not linked to `Html::write`: a call of a
tuple struct gave no type. It is now a value of the struct its path resolves to, as Python's `Html(text)` and TypeScript's
`new Html(text)` are, so the call edge is drawn in all three languages.
