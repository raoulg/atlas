What `atlas changes` says a changed type or place was names each function and type the way the view draws it. A method
has its class (`Block.scaled`, where it said `scaled`), and an initializer is the call to its class (`sparse.Rows()`,
where it said `__init__`). A type whose name another type of the program shares has the last part of its module
(`sparse.Rows`, `model.Node`), as `typeLabel` does. One function says each, `model::said`. Two methods of one name on two
classes are now two names, so a list that counts them counts both.

No picture: the page already drew these names. What shows the change is the output of `changes` on the program of
`engine/tests/one_name.rs`. Its types `Rows` are dense rows in `blocks.dense` and a sparse class in `blocks.sparse`, and
a block holds a sparse mask. The second commit adds a method on the dense rows:

```text
changes HEAD~1..HEAD
  0.71.0 (f239e878)     ~ step Block: was Block: with __init__, masked, scaled · holds mask: Rows
                        ~ step dense.Rows: was Rows: taken by __init__, of, scaled · given by filled, ones, scaled · one of …
  with #369 and #370    ~ step Block: was Block: with Block(), Block.masked, Block.scaled · holds mask: sparse.Rows
                        ~ step dense.Rows: was dense.Rows: taken by Block.scaled, sparse.Rows(), sparse.Rows.of · given by Block.scaled, ones, sparse.Rows.filled · one of …
```

A place's words move only where a class's name is shared. For example, they say `cache.Cache.get reads` where they said
`Cache.get reads`, since Atlas Studio has a `Cache` of its own (`update.Cache`); that is the view's name for the step. No
step or place is added, removed or marked otherwise.
