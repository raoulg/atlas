The view of all routes of a kind (every command, every export) draws each route as its route's own picture closed
(#434). A command takes the command line it starts from, the values it reads from beyond it and the errors it hands
on, and it gives the figures it draws. Before, the box of a route showed only what the function's own signature and
touches said, so a command started from nothing and a figure it drew on was left out. In the sunspots pipeline's
exports, `sunspots.Plot` now starts from its entry, takes the `Plot` and `Trend` values its methods run on and draws
`File(*.png)`, the figure it saves; before, it gave a `Figure` and a file named after the class.

Every view the page draws (the overview, a part, a focus, the routes of a kind, a route) is now the image of its own
fine plan through one function, from one view state: what the reader looks at and what they have open. A type in
the overview stands in the package that holds everything that makes or takes its family, whichever packages are
open, so opening a package no longer moves a type that the package only takes into that package.

One law holds all of it on every small program (`every_view_state_draws_the_image_of_its_plan`): it walks the view
state, closed, one box open at a time and sets of boxes drawn from a seed. A coordinate a view does not read changes
nothing, and every picture drawn again is the picture it was. The routes whose box at the cut still differs from
their picture closed are #438.

Kind: drawn wrong, now right.
