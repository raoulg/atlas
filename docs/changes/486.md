In Studio's file tree a folder's chevron opens and closes it, and a click on its name shows the folder: the route
`atlas-code view <folder>` opens on, the module the folder's scripts run, or the overview where they run none. Before,
a click on a folder only opened it, and nothing in Studio showed a folder. A file shows what `atlas-code view <file>`
opens: a file that defines a module and runs it in its own script opens on that module, where it opened the script
before, from the tree and from the command line alike. In a lesson, the folder `exercises/` and its `designs.py` both
open on `Head`'s forward pass. Studio asks `atlas-code serve` where each place starts; the rule is the engine's, one for
a folder and a file.
