The picture's lines open round, each corner an arc; the square lines are one click away, and the route of a line is the
same either way. What the reader chooses on the page (the lines' shape, the code panel, the legend's help) was kept per
browser address, and `atlas-code serve` and Studio serve each repository at an address of its own, so a choice made in
one repository was gone in the next. A served page now also keeps the choices in one file of the reader's,
`~/.config/atlas/viewer.json` (`%APPDATA%\atlas\viewer.json` on Windows), and every served page opens with them.
