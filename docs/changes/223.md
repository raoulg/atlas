Homebrew installs Atlas Studio on a Mac, as it installs the CLI: `brew install --cask raoulg/tap/atlas-studio`, or
`atlas-studio-nightly` for the nightly. Studio is signed ad hoc, so macOS blocks its first start once: open it, then
allow it in System Settings › Privacy & Security › Open Anyway. Studio's own updates open without asking again. The tap
gets the cask from the first release and the first nightly made after this lands. No screenshot: what shows is the
install's output.

```text
$ brew install --cask raoulg/tap/atlas-studio-nightly
==> Installing Cask atlas-studio-nightly
==> Moving App 'Atlas Studio.app' to '/Applications/Atlas Studio.app'
🍺  atlas-studio-nightly was successfully installed!
==> Caveats
Atlas Studio is signed ad hoc, not with an Apple Developer ID, so macOS blocks
its first start. Open it once, then allow it in
  System Settings > Privacy & Security > Open Anyway
```
