A torch model calls its submodules (`self.encoder(x)`, `model(x)`), and `nn.Module` runs their `forward`. Atlas did
not follow such a call, so a model's forward pass drew as nothing unless it was rewritten as explicitly typed stage
methods called as `model.forward(x)`. The values between the steps also lost their jaxtyping shape: a type checker
reads `Float[Tensor, "batch 128"]` as a plain `Tensor`, and so did the wires.

Now a call of a torch module is the call of its `forward` (the first one along its class's bases), on the module
called, so `self.head(x)` and `self.head.forward(x)` draw the same. Every wire carries the shape the code declares: a
parameter's or an annotated local's, what the code's own function returns, and the part of a returned tuple it
unpacks. The rule is torch's alone: a class that is no module is called through its own `__call__`, and so is a module
that defines one.

Kind: drawn wrong, now right.
