To know what a body's own code uses, Atlas asks of every name where it is read: there, where a name bound to it is
read, or nowhere. It asked the same name up to three times, and at each node on the way up to the body it collected
that node's children and walked them for the name anew. It now keeps each name's answer for the body, and reads the
children and the names from the reading of the body it already holds. Nothing Atlas reads, draws or checks changes:
`atlas-code --no-cache analyze` gives the same bytes before and after on 303 subjects (Atlas itself at `--libraries`
0, 1 and 2, every pair under `engine/tests/pairs` and every fixture).

Bars: Atlas reading itself cold, before = 9.85 s; Atlas reading itself cold, after = 8.99 s; what bodies' own code uses (`uses`, summed over threads), before = 2.37 s; what bodies' own code uses (`uses`, summed over threads), after = 1.72 s | `atlas-code --no-cache view --timings` of Atlas itself at `--libraries 1`, `next` at `b5769c64` against `stood-384` at `f0c4bce7`, seven interleaved rounds on a developer machine (Apple silicon, other work running), the median of each; every round of the branch was faster than the round of `next` beside it. `perf.yml`'s `compare` mode on its runner is [run 41457078412](https://github.com/raoulg/atlas/actions/runs/41457078412).
