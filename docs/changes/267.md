Deciding a vision (`prophetize`) places each of its files at the path the vision names it by, also when the vision
shares nothing with the tree: the first module of a project that has only its manifest, a package that does not
exist yet. Nothing in the picture changes; the answer of the MCP tool shows it.

The vision is read in a copy of the tree, and Atlas now keeps the directory it read the copy from, so it knows where
every file of the vision lies. Before, it worked that out from an item the tree and the vision both hold, and a vision
that holds none was refused. 0.69 decided such a vision by the file's name alone, the match #258 showed could take
another file of the same name; the refusal never reached a release.

```text
vision of src/archive/vault.py, in a project with only pyproject.toml
  before   the vision holds no item the tree holds, so Atlas cannot tell where its files lie
  now      Decided: a vision. Written: src/archive/vault.py. Marked as prophecies: archive.vault.Vault. …
```
