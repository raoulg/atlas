When Studio's app was replaced while it ran (by `brew upgrade`, or the install script), the window kept the build it
started as, but asked the app on disk which build it was: the status bar said 0.72.0, while *check for updates* said
Atlas Studio was up to date and What's New showed 0.72.1's notes.

Now Studio keeps the build it started as for as long as it runs, and says the one installed under it: *Atlas Studio
0.72.1 is installed*, with that release's notes and a Restart button, and `↻ Studio 0.72.1` in the status bar beside
the build that runs. What's New and the update check speak of the build that runs.

Kind: drawn wrong, now right.
