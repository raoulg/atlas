title: An all route serves every method

A route registered with `app.all(path, ..)` (Express, and Hono, Koa's router and Fastify alike) was read as a `GET`
route, so a `POST` to its path, from the same program or from another part, met no route. It is now the route at its
path for every method, `GET|HEAD|OPTIONS|POST|PUT|PATCH|DELETE`, and a request at the path meets it whatever its
method; its box keeps the name the code gives it, `ALL /path`. The methods pair (`engine/tests/pairs/methods/typescript`)
shows it: a page that reads its notes with a GET and keeps one with a POST, served once by one handler for each method
and once by one handler for every method.

```text
atlas analyze engine/tests/pairs/methods/typescript/shortcut      (server: app.all("/api/notes", ..))
  before   route  GET /api/notes
           asks   page.notes -> GET /api/notes
                  (page.keep, a POST, meets no route)
  after    route  GET|HEAD|OPTIONS|POST|PUT|PATCH|DELETE /api/notes      (box ALL /api/notes)
           asks   page.notes -> ALL /api/notes
           asks   page.keep  -> ALL /api/notes

atlas analyze engine/tests/pairs/methods/typescript/clean         (server: app.get(..), app.post(..))
  before and after
           asks   page.notes -> GET /api/notes
           asks   page.keep  -> POST /api/notes
```
