A loop that uses its element twice in one path (`root / kind / f"{kind}.csv"` for each `kind` of `["books", "games"]`)
drew every pairing of the two uses: `out/books/books.csv` and `out/games/games.csv`, but also `out/books/games.csv` and
`out/games/books.csv`, files no run writes. Now a name the code binds once is one value wherever it stands, so the
route writes the two files it writes. Two values the code keeps in step only by an index it counts (`FOLDERS[i]`,
`NAMES[i]`) are still two values, and Atlas still draws every pairing of them: the code does not say they belong
together. The same in Python, Rust and TypeScript (the pair `twice`).

```text
example: engine/tests/pairs/twice/python/clean, route export.main
  next (9cce2767)     writes out/books/books.csv, out/books/games.csv, out/games/books.csv, out/games/games.csv
  with #324           writes out/books/books.csv, out/games/games.csv
on Atlas itself: the prophetize test writes $TMPDIR/atlas-prophetize-{js|mts}-{value}/src/index.{js|mts} in two places,
  no longer four
```
