The overview has four columns, so that the same things are found in the same place: what the packages read of the world,
the packages, the types that cross between them, what they write. A line between a package and a type says its way by
its arrowhead, a call between two packages is a dotted arc beside them, and a line's width and tooltip say how many lines
it stands for. The program's own types that cross between packages are one box, `expenses · 6 types`, beside each
library's; a click opens it into the types, and in an opened package the types that stay inside it fold the same way. A
place the program reads and writes counts in its kind on both sides (`from Disk · 25`, `into Disk · 8`) and no longer
stands as a third box in the middle. What a package takes of a type and what it gives of it run on one line with an arrowhead at each
end. In a focus every class and function is a row of its own, so a module of five classes that all take and give the same
types shows five rows, not one box that names two of them.
