One rule for what an object holds, the same in Python, Rust and TypeScript: a field is what the constructor that built
the value set it to, completed by the call that built it. It closes three issues and moves a fourth.

- **A value built in place reads its own field** (#407). `Shelf::new(PathBuf::from("drafts")).index()` in `read_index`
  reads `drafts/index.txt` alone. Before, Rust read a field as every struct literal of the type at once, so `read_index`
  also read `archive/index.txt`, the index of a shelf another function builds. A struct's literal is now a call of the
  struct's constructor, as a class's call is in Python and TypeScript.
- **A place is credited to whoever writes its start** (#395). Where the constructor puts the folder under one it names
  itself (`self.root = Path("shelves") / name`), the note written on the shelf is decided by the constructor; before, it
  was credited to the method that joins the file's name below it. A shelf a function builds and hands on is made whole by
  that function and the method together, in every language (Rust named only the method where a loop rebinds the shelf).
- **A variant's field is carried through the `match` that takes it apart** (#349). `Plek::Bestand(pad) => fs::read_to_string(pad)`
  and `case Bestand(pad): pad.read_text()` read the file the variant was built with (`bijlagen/bron.txt`), decided where it
  is built; before, the read was a value the code does not name. TypeScript's discriminated unions are not read this way yet.
- **`bool::then_some` holds what it is handed** (Rust): `(!clone).then_some(repo)` is `repo` where it holds a value, as
  `if !clone { Some(repo) } else { None }` is.

The completion through the callers stays capped (#406): without the cap, one path of Atlas's own (`Environment::manifest`)
completes to 662,144 distinct completions, 205,677 terms over 156,106 conditions, and a cold read takes over 200 s instead
of 19 s. A completion is now followed once for each value and depth it is met at, and kept once, so the cap counts
distinct completions.

The pair `engine/tests/pairs/fields` writes the shelf in each language, and
`a_field_holds_what_the_constructor_that_built_the_value_set` holds in all six readings the index read on the shelf built in
place, the conjunction that makes the handed-in shelf's note whole, and who decides it. `sums/kept` keeps an attachment's
place in a variant on the clean side and in a string on the shortcut's, and
`a_variant_s_field_taken_out_by_a_match_is_the_value_built_in` holds it in Python and Rust.

Kind: drawn wrong, now right; forms drawn alike.
