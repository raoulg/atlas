Nothing in the picture changes. A reading still links every body it reads, a library's included: the graph keeps of a
library a restriction of the code it read, so a class it keeps is a door by any of its operations, a parameter holds
what any call fills it with, and a path is made whole by any of its callers, whether the program reaches that code or
not. A graph's stats now count the bodies its reading linked (`linked_bodies`, and of those `linked_library_bodies`),
`atlas-code view --timings FILE` names them under `linked`, and the nightly measure records them
(`read/<subject>/<cold|warm>/linked/<program|library>`). Atlas reading itself, cold and then warm, when the graph and
its count come from the index:

```text
cold  {"check":0.019608209,"flow":0.30544925,"linked":{"library":4143,"program":3028},"page":0.037173958,"read":22.761174666}
warm  {"check":0.018807541,"flow":0.303005834,"linked":{"library":4143,"program":3028},"page":0.035623375,"read":0.135321584}
```
