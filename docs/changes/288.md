Nothing in the picture changes. A reading still links every body it reads, a library's included: the graph keeps of a
library a restriction of the code it read, so a class it keeps is a door by any of its operations, a parameter holds
what any call fills it with, and a path is made whole by any of its callers, whether the program reaches that code or
not. `atlas-code view --timings FILE` now also names how many bodies the reading linked, the program's and the
libraries', under `linked`, and the nightly measure records them (`read/<subject>/<cold|warm>/linked/<program|library>`).
Atlas reading itself, cold and then warm from its index:

```text
cold  {"check":0.019954083,"flow":0.361868917,"linked":{"library":4143,"program":3028},"page":0.043654583,"read":14.614618292}
warm  {"check":0.02189775,"flow":0.343956583,"linked":{"library":0,"program":0},"page":0.033708833,"read":0.161464834}
```
