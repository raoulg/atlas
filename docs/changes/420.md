Before, a shaped array of the rank families was named for its rank (`Float Tensor · 2D`, `Float Tensor · ≥1D`), but
one written as `Float[Tensor, "..."]` was drawn raw, `Float[Tensor, ...]`.

Now a shape that is one `...` alone, which promises no axis, is named for what it says: `Float Tensor · any rank`. A family
of rank at least 0 reads "any rank" too. A shape the code writes with its own axes, `_ _` or `*lead`, keeps its own name.
