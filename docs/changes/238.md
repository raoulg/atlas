The nightly installs as a command of its own, `atlas-nightly`, beside the release's `atlas`, as Studio's two channels do:
`brew install raoulg/tap/atlas-code raoulg/tap/atlas-code-nightly` (the two no longer exclude each other), or `install.sh`
with and without `ATLAS_CHANNEL=nightly`. An agent is given the nightly with `atlas-nightly mcp`; Atlas Studio Nightly's
Settings › Coding agents registers `atlas-nightly`. Who has the nightly through Homebrew today keeps it as `atlas-nightly`
after `brew upgrade`, and no longer has an `atlas` until the release is installed beside it: an agent registered with
`atlas mcp` then needs either. What shows is the two commands in one folder:

```text
$ ATLAS_CHANNEL=nightly sh install.sh && sh install.sh
atlas installed in ~/.local/bin/atlas-nightly
atlas installed in ~/.local/bin/atlas
$ atlas-nightly --version; atlas --version
atlas 0.68.0-nightly (9a08af6)
atlas 0.67.2 (3541cb3)
```
