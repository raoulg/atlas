The weekly benchmark, which gives a release its `Bench:`, no longer compiles Atlas. Each side reads with the build a
release on GitHub holds of it: the stable release's archive at its tag, else the nightly built from its commit. A side
without one is built on the runner, and the standing says so. It reads three programs, each at its fixed revision
(`atlas-0.70.0`, `private-1`, `vectormesh-locked`), cold and warm, with the cold reading's peak memory, in three
interleaved rounds. A release's `Bench:` comes from the latest weekly run, or from one dispatched with
`to=origin/release-X.Y`, and does not wait on a run of its own. The nightly series reads the same three programs the
same way, with the newest nightly build, and skips a night that has no new one.

```text
weekly run, v0.72.2 against release-0.73      before        now
one run                                       2 to 4 hours  19 min 25 s   (run 42391527555)
```
