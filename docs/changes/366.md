A list the body makes by its own code (`let mut both: Vec<&Level> = vec![]`, `both: list[Level] = []`, `const both:
Level[] = []`) and then changes in one arm of a choice stood in that arm's frame, and the step after the choice took what
the arm made, as if the arm always ran. The list now stands in the body's frame, where it is bound, and what the arm
makes of it is the choice's value, which the arm that does not run keeps: the step after the choice takes that value, as
it already did of a list a step made. In a loop the change was not handed the body's list at all where the loop gives a
value of the same type (`for level in levels { every.push(level) }` pushed onto the level); it now takes the list. The
same holds in all three languages, for a list of names (`vec![first]`) as for an empty one.
