Shift-click puts whatever the picture draws as one box in focus: a package, a class, or a base class with the classes that
keep its promise. The picture is then that box with the types it takes and gives, the places it touches and the rest of
the code on either side, as it was for a package. A box inside the focus narrows the focus to it, so from a package one
walks down to a module and to one class in it without the picture growing; a box of the rest is added to the focus, as
before. Beside a class in focus, the other classes of its package stand in the rest.

The bar above the picture reads in two lines. The first says where the reader is, as a path: the program, then the
route or the focus with the packages above it, each a click back to it (`harvest › store › ReadingStore`). The second
says what is folded, each fold a switch: the test code, the errors, what a route's steps run on, a package grouped by
base class. What is opened is counted there, with the list on request and one button to close it all. The overview and a
focus count their errors on the box that hands them on (`+1 error`), as a route does, and the switch `errors` draws them.
