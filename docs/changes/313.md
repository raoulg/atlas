In vectormesh, the route `TransformerBlock` drew `Tensor → forward` with `forward` closed, and lost that line when
`forward` was opened: inside, `_pad_mask` stood as `TransformerBlock._pad_mask · +2 types`, a count that folded the
`tensors` the body binds anew (in a frame inside `forward`) together with a `Tensor` from beyond. Now a count folds only
values from beyond; a value the body makes in its own frame is drawn by itself, `Tensor · tensors`, and the `Tensor`
from beyond comes into `_pad_mask` by its own line, the line the closed box drew.

The door's parameter `tensors: Float[Tensor, "batch seq {self.hidden_size}"]` is again the named value it was in 0.69:
the engine held its type as `hidden_size}]`, cut at the dot in the shape, where it now holds
`Float[Tensor, batch seq {self.hidden_size}]`.

What the `Tensor` from beyond is, `_pad_mask`'s own `pad_mask`, is #318; the program
`engine/tests/plans/door-shaped-param` holds the law in `plans.rs` and `pictures.py topology`.
