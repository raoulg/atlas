A decision sets a finding of `atlas-code check` aside (#120): a comment in the code, or a line of `.atlasignore` at the
top of the repository. `check --help` named the file only under `--all`; now it ends in a section that shows both forms
and the file's format, and the guide's Check section does the same with an example. Nothing check reads or finds
changes; `-h` stays compact.

```text
$ atlas-code check --help
...
Decisions:
  Where the code is right as it is, write the decision down with its reason: check sets the
  findings it answers aside, counts them, lists them with --all and keeps them in --json.

  In the code, after the line comment, for that line or the line below:
    # atlas: ignore[changes] in place for the frame rate
  For whole paths, one a line in .atlasignore at the top of the repository:
    src/sim/particles.py  changes  # in place for the frame rate
    src/legacy/**                  # ported pipeline, rewrite planned
  A pattern as .gitignore writes one, the principles it answers, the reason after #.
  No principle named answers them all; a decision that answers nothing is asked about.
```
