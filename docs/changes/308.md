Who makes a path whole is a set of alternatives, any of which is enough. One alternative can contain another: in the
`lens` pair, a Roster read with `load`, or reread from one that `load` built, makes `Roster.add`'s file whole. The
longer alternative holds only where the shorter one does, so it says nothing more (`a ∨ (a∧b) = a`). Atlas no longer
writes it. Nothing on the page changes, because every route and every step runs the same touches as before. What
changes is the graph's JSON: 11 of 293 pair programs drop an alternative, for example `atlas-code analyze` of the lens
club:

```text
lens/python/club/clean, the touch of `club.files.Roster.add`:
  before  "by": ["club.files.Roster.__init__&club.files.Roster.reread", "club.files.Roster.load",
                 "club.files.Roster.load&club.files.Roster.reread"]
  after   "by": ["club.files.Roster.__init__&club.files.Roster.reread", "club.files.Roster.load"]
```

A caller that stands only in such a longer alternative no longer counts among the callers a step's arrow depends on.
`harvest.cli.report` is one: the harvest program's weather request (`pairs/python/clean`) was written as made whole by `api.collect&cli.report`
and by `cli.collect&cli.report` beside `api.collect` and `cli.collect`. `reread` still counts, through
`Roster.__init__&Roster.reread`. No call, request or finding moves.
