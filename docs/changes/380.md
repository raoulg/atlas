In Rust, `let (mut asked, mut unknown) = (vec![], false)` binds `asked` and `unknown` each as `let mut asked = vec![]`
and `let mut unknown = false` would. A name bound `mut` and changed in place (`asked.push(s)`) holds a value of its own,
which each change makes anew, so a part of it (`asked.first()`) takes that value, and what is built from the part takes it
in turn. Before, the push gave nothing and the part took nothing.

A tuple pattern as a parameter, `fn f(n: &mut Node, (params, returns): (A, B))`, reads as `fn f(n: &mut Node, given: (A, B))`
with `let (params, returns) = given` does: one parameter of a product type, one slot at its place in a call, and each name
the pattern binds a part of that parameter. A step handed `params` is handed what the parameter holds.

```text
example: engine/tests/pairs/assigned/rust, set_holds and gather
  given + let (params, returns) = given     extend · handed Node, Level · given
  (params, returns) as the parameter        before: extend handed Node only    now: extend handed Node, Level · (params, returns)
```
