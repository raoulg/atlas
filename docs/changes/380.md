In Rust, `let (mut asked, mut unknown) = (vec![], false)` now binds `asked` and `unknown` each as `let mut asked = vec![]`
and `let mut unknown = false` would. A name bound `mut` and changed in place (`asked.push(s)`) holds a value of its own,
which each change makes anew, so a part of it (`asked.first()`) takes that value, and what is built from the part takes it
in turn. Before, the push gave nothing and the part took nothing.

A tuple pattern as a parameter (`(params, returns): (Vec<..>, Option<..>)`) is still one parameter named by its text. A
parameter of its own for each name moves the places a call's arguments fill, which the builder counts for every language;
the pair holds the law as an ignored test until a tuple argument is spread over them.

```text
example: engine/tests/pairs/assigned/rust, gather
  one let per name      push · changes asked
  one tuple pattern     before: push gives nothing    now: push · changes asked
```
