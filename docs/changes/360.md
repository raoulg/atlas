An agent reads a route as text (MCP `route`) and the human reads it on the page. The text now places what each step
touches as the page does: under the calls that lead to it and after what ran before it, such as a shelf set up two
steps earlier. It placed a step only by the calls above it before, so where an earlier step decided the folder, the
text said a parameter's name and the page said the file.

```text
shelf.cli.main (pairs/setup/python/clean), MCP route, depth 2                                     the page draws
before                                          with #360
1  open_shelf() → Shelf                         1  open_shelf() → Shelf
  1.1  Shelf()                                    1.1  Shelf()
2  Shelf.keep_report(text)                      2  Shelf.keep_report(text)
  2.1  write(path, text) · writes write.path      2.1  write(path, text) · writes out/report.txt    out/report.txt
3  Shelf.keep_log(text)                         3  Shelf.keep_log(text)
  3.1  write(path, text) · writes write.path      3.1  write(path, text) · writes out/log.txt       out/log.txt
```

The same holds in a loop and in a nested arm, and on a class's own route, where each method runs on what the class's
constructor holds:

```text
                                               before                    with #360                          the page draws
plans/setup-in-a-loop   rounds.main  2.1 write  writes write.path         drafts/report.txt | out/report.txt  drafts/report.txt, out/report.txt
plans/setup-in-an-arm   arms.main   1b.1 write  writes write.path         out/report.txt                      out/report.txt
collections/python      Store   2.1 Store._rows reads self.path           reads Store.path                    Store.path
collections/python      Store   2.4 write_rows  writes write_rows.path    writes Store.path                   Store.path
```

A step sends the reader to an earlier one (`→ see 2.1`) only where its body touches the same places there. On Atlas's
own `atlas-code.main` at depth 4, `merged → see 1.5a.6.1a` is now a step of its own, since `Repo.resolved` checks
another path under it. At the default depth the route reads as it did.

```text
MCP route on Atlas's atlas-code.main, release build, the graph already read (six runs each, a loaded machine)
depth 2 (default)   before 0.15–0.19 s   with #360 0.15–0.19 s   44 lines both
depth 4             before 0.16–0.20 s   with #360 0.16–0.21 s   499 lines, 516 lines
```
