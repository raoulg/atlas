In the Type lattice, space over a class shows its details and code over the picture, as it does over a box in the
Flowchart. A double click on a class (or the button "light its values in the Flowchart" in its details) opens the
Flowchart on a route that holds a value of that class or of a class below it, and lights every box of those types; the
rest of the route stays, dimmed. Picking the base of a family lights the family's closed box; picking one kind of it
opens the family, so that only the boxes of that kind are lit. A box that holds such a value inside (a closed step, a
family holding it as a part) is lit dashed; opening it shows the lit box. The state bar names the lit type, with an ✕.
