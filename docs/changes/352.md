A key taken as the place a file has within its folder (`note.relative_to(root)`, `note.strip_prefix(root)`,
`path.relative(root, note)`) and joined back to that folder (`root / key`) is the file it was taken from. Atlas did not
see this. It read `notes/notes/*`, or a name of its own under `notes/`. Now `strip_prefix`, `relative_to` and Node's
`path.relative` are one operation in every language, which a join at the same folder undoes. This also holds where the
function that takes the key and the function that joins it back are different functions. So what is read back is the
note that was listed. A key cut out of the path's text by its length (`str(note)[len(str(root)) + 1:]`) is still a name
Atlas does not follow (the pair `keys`).

```text
example: engine/tests/pairs/keys/python/clean, route notes.main
  next (06afdeda)     read reads notes/notes/*   (Rust: notes/{main.name}, TypeScript: notes/{call})
  with #352           read reads notes/*, the notes main lists, in all three languages
the gate (every program under engine/tests/pairs and plans): only keys moves among the pairs (one touch on each clean side)
on Atlas itself: what a TypeScript library's package.json and code are read at (Environment.manifest, package_code)
  is no longer held by Libraries (45 and 29 touches, at {root}/{value}/package.json) but by Environment, at
  {a}/node_modules/{name}/package.json: 48 → 10 and 31 → 5 touches. Environment.real, Repo.has and Tmp.link now
  complete to the subjects the tests read.
```
