The history's first row was always the working tree, "Working tree · clean" when it held nothing new, and the
header said "B working tree alone". Now HEAD's commit is a hollow dot, and the working tree has a row of its own,
**Uncommitted changes**, only while it holds changes; the header says **showing** one revision or **comparing** two.
A click shows that commit on its own, read from the commit; a ⇧ click compares it with the one shown. **files** shows
the commit's files instead of its picture, markdown rendered with its pictures. Right-click a commit to copy its hash
or subject, add a tag, check it out, or pull and push the branch HEAD is on; each of these asks first and names the git
command it runs.
