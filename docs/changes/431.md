The overview and a focus draw the types of a library inside a frame of that library, the way a place lies inside the
folder it is in. A tensor annotated with jaxtyping is torch's (the array type it names), so vectormesh's eleven rank
families of `Tensor` stand in one `torch` frame with `nn.Module` and `Optimizer`, instead of loose among the program's own
classes. Clicking the frame's
title closes it to one box, `torch · N types`, whose lines are the lines of its types merged; clicking the box opens it
again. A library with one type in the picture is that type, without a frame. Rust's ndarray arrays get a frame the same
way; Rust and TypeScript do not read a dtype or rank yet, so their arrays are not grouped into rank families.
