The nightly of Atlas Studio is an app of its own, **Atlas Studio Nightly**, with its own settings and list of
workspaces, so it installs beside the release: `brew install --cask raoulg/tap/atlas-studio raoulg/tap/atlas-studio-nightly`,
or `install-studio.sh` with and without `ATLAS_CHANNEL=nightly`. When a nightly breaks, the release is at hand. A nightly
Studio installed before this is called Atlas Studio: its next update installs Atlas Studio Nightly beside it and starts
the old one again. Open Atlas Studio Nightly from then on (its list of workspaces starts empty) and remove the old one,
or install the release in its place.
