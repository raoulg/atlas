A click on a file in Studio's tree, or `atlas-code view <file>`, opens the view of that file, and "show code" beside it
shows the file, whole. Before, the panel said "Nothing selected" until a box was clicked. A view opened on no file (a
folder, the repository) shows the file its route starts in, and a selected module shows its whole file, where it showed
the first 60 lines.
