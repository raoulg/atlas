Before, Studio's `atlas serve` ended with Studio only when Studio was quit; `kill`, `pkill` or a crash left the server
running. Now it and the terminals' shells end with Studio however Studio ends, `kill -9` included. For a program that
starts the server itself, `atlas serve --exit-on-stdin-close` serves until its standard input closes; from a terminal,
`atlas serve` is unchanged. Nothing shows on screen; the repro does: after
`pkill -f 'Atlas Studio.app/Contents/MacOS/atlas-studio'`, or `kill -9` of Studio with a terminal open,
`pgrep -fl 'atlas serve'` lists no Studio server and the terminal's shell is gone.
