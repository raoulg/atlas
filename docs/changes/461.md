Below a module Atlas drew every method as a box of its own. The hierarchy now goes on: a class closed is one box, the
arrow from what its methods take to what they give; the classes that keep the promise of one base are one box above
them, `Pool · 2`, and each opens with a click. A package of modules can be grouped by base class instead of by module
(the state bar's `+ <package> by base class`). Classes that share no base in the code are no family in the picture.
