A step built with its settings and then run (`scale = Scale(2.0)`, later `scale.apply(readings)`) applies the arrow the
instance carries. The route says so on the step, `scale.apply`, and draws no line from the instance to it: what is left
is the chain the data takes. Inside an opened method the same holds for the steps it runs on itself (`self.narrow(x)` is
`model.narrow`) and on a part of itself (`self.conv(x)` is `model.conv.forward`). The chip `said by name ✕` above the
picture draws the lines again; `receivers: true` in a view does the same.

A line from an instance that stays is therefore a fact: the step takes the instance as an input (`shift_with(scaled,
shift)`) or the caller takes a setting out of it (`scale_by(readings, scale.by)`). A value no constructor made here, a
tensor or a path a method is called on, keeps its line: it is the data.
