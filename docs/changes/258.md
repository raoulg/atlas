Where Atlas writes into your tree, it writes what it was asked to and nothing else. Nothing in the picture changes;
the marker lines and the answers of the MCP tools show it.

Breaking a seal (`unseal`) takes out `sealed=..` and the separator that joins it, in every language's marker, and
leaves every other byte of the file as it was. In 0.69 a Rust marker lost the space after `prophecy:` as well:

```text
before   #[doc = "prophecy: supersedes=archive.Sink sealed=#7"]
unseal   #[doc = "prophecy:supersedes=archive.Sink"]       (0.69)
unseal   #[doc = "prophecy: supersedes=archive.Sink"]      (now)

before   @prophecy(sealed="#8", supersedes="archive.sink.Sink")
unseal   @prophecy(supersedes="archive.sink.Sink")

before   /** @prophecy sealed=#9 */
unseal   /** @prophecy */
```

A file emptied or shortened after Atlas read it (`atlas serve` and the MCP server keep a reading) is an error that
asks to read it again; in 0.69 the call crashed.

Deciding a vision (`prophetize`) takes the file the vision's path names from the directory it was asked for, and no
other file of the same name. In 0.69 a vision of `sink.py`, asked for the package `src/archive` on its own, was refused for an
item of `src/archive/store/sink.py` it never named; a vision asked for a directory the project is a part below
(`py/src/archive/sink.py`) marked nothing:

```text
vision of sink.py, asked for src/archive
  0.69   the vision changes `archive.store.sink.Shelf.keep` in `sink.py`: writing it would replace what is built …
  now    Decided: … Marked as prophecies: archive.sink.Vault.

vision of py/src/archive/sink.py, asked for the repository
  0.69   Decided: … Marked as prophecies: nothing.
  now    Decided: … Marked as prophecies: archive.sink.Vault.
```
