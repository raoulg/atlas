A repository whose parts pin two versions of one library (Atlas's own `Cargo.lock` pins `serde_json` 1.0.151, the
Studio's 1.0.154) held both readings under one name, so one part's routes could draw the other version's code, and
`atlas-code changes A..A` compared the two versions with each other and listed hundreds of changed routes. Each
version is now a library of its own, named after it (`serde_json-1_0_151`, `serde_json-1_0_154`), and every route
goes through the version its part runs. A library the parts read at one version, from one place, keeps its plain
name and is one box both parts point to; a name past the code both parts name is one box too. In the pair above,
`billing` runs `notekit` 0.2.0, whose `save` writes `bills.txt.part` and renames it to `bills.txt`: it was drawn
with 0.1.0's `save`, as `orders` runs it, and is now drawn with its own.
