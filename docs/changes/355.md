A name bound to a list of names (`let mut both = vec![first]`, `both = [first]`, `const both: Level[] = [first]`)
stood for those names even where a step then changed the list in place: `both.push(second)` was handed `first` and
gave `first` anew, and the step that listed `both` took `first`, as if the list were the level. A change in place
binds the name anew, as `p.push(x)` is `p = p.join(x)` for a path, so the list is now a value of its own from where
the body binds it: the body's own code makes it there of `first`, the push takes that list and `second` and makes it
anew, and the step after it takes what the push made. The same holds for a function of the program's that changes
what it is handed (`add(both, second)`, in Rust `add(&mut both, second)`), for a change in one arm or in a loop, and
in all three languages. A list written out once (`vec![first, second]`) still stands for the names it holds.

```text
example: engine/tests/pairs/locals/rust/shortcut, route signal.gathered
  0.71.0 (0dfd0fee)   Level · first, Level · second → push → Level · first → list
  with #355           Level · both, Level · second → push → Level · both → list
analyze --no-cache, Atlas and every program under engine/tests/pairs (334 subjects), base against branch, with the
counted names of unnamed values numbered per function: 5 move. The locals pair's `gathered` and `lent`, shortcut in all
three languages, now change the list's own value. In the changes pair's Python `extended` (`xs = xs + more;
xs.append(0)`) the append no longer runs on the two parameters. In Atlas's own code 7 functions that keep a stack or a
list made of names (`let mut stack = vec![start]` in `Graph::reach`, `flow::contexts`, `principles::holds`,
`Places::reaches`, `tree::holds`, Python's `Seen::held`, `linearization`) hand the stack to the steps that pop and push
it instead of the names, and read the names where they bind it; 5 gain a step for a change of Rust's collections the
table now names (`retain_mut`, `extend_from_slice` twice, `dedup_by`, `insert_str`); and `principles::doors` gives
`let own = [Signature { .. }]` the class of its elements. Atlas's findings do not move.
```
