title: A TypeScript package linked into node_modules is read anew when its code changes
area: engine
commit: 444ef348
pictures: []

A `file:` dependency is installed as a link in `node_modules` to a directory elsewhere, and Atlas reads its code from
there. The cache now checks the code the link points to, so an edit in such a dependency is drawn on the next reading
and the page no longer shows the library as it was. Python's path dependencies (a `.pth` file naming a source
directory) were already checked this way. Nothing changes in a picture; the cache test
`a_library_read_through_a_link_is_read_anew_when_its_code_changes` holds the law for both languages.
