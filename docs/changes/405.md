The programs Atlas is timed on and sampled on are now read as their authors have them: every committed lock file is installed by its tool before the reading (`uv sync --frozen` into the program's `.venv`, `npm ci` into `node_modules`, `cargo fetch --locked` as before), so Atlas reads a Python or TypeScript program's libraries as it does for a user. Measured numbers of those programs rise to what a user waits for; a Python program read with its `uv.lock` is measured under a new name (`goad_toolkit-locked`, `vectormesh-locked`), so its series starts afresh rather than stepping. `ordash` has only a `Cargo.lock` and keeps its series. Nothing in Atlas's output changes: the change is in `tools/perf.py corpus fetch`, with the downloads of `uv` and `npm` kept between runs by `perf.yml` and `laws.yml`.
