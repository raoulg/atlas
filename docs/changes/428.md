One rule for a kind of input, the same in Python, TypeScript and Rust: a value the caller may hand or leave out is
its default where no caller hands it, and the default is the caller's to override. It closes four issues.

- **A caller that hands nothing writes where the default says** (#383). `save_report("draft")` beside
  `save_report("final", Path("out/report.txt"))` writes one file, `out/report.txt`, whether the default is the
  parameter's (`path: string = "out/report.txt"`), a fallback in the body (`path ?? "out/report.txt"`,
  `path or ...`) or an `Option` the function unwraps (`save_report("draft", None)`). Before, TypeScript drew the
  call that left the path out as the parameter's name (`saveReport.path`), and handing `None` or `undefined` counted
  as a value.
- **A fallback is completed by the callers, as the same path written in place is** (#350). `keep(text, home, out=None)`
  that writes `out or made(home, "kept.txt")`, called with `Path("work")`, writes `work/.made/kept.txt`, the file
  `made(Path("work"), "kept.txt")` names where it is written out. Before, the callers' values stopped at the default,
  which was drawn as `{home}/.made/kept.txt` or as an unnamed `kept.txt`.
- **An empty default keeps the root of the path it is joined into** (#428). `join(process.env.RAW ?? "", kind,
  "download.json")` is `{$RAW}/{kind}/download.json`, as `process.env.RAW!` is; before, the empty default dropped the
  root and the file was drawn as `{kind}/download.json`, a place the program itself decides.
- **The empty path is the unit of a join on both sides** (#427). `Path("x") / ""` is `x` after any base, also where a
  caller hands the empty path into a term (`base/{p}` handed `""` is `base`); the law
  `paths::tests::a_join_commutes_with_what_is_handed` holds it with the case proptest shrank to.

The pair `engine/tests/pairs/defaults` writes the program in each language, with each language's own form of a default
on the clean side and the fallback in the body on the shortcut, and `an_input_is_its_default_where_no_caller_overrides_it`
holds in all six readings the same report, the note completed to where it is written in place, and the download's
root.

Kind: drawn wrong, now right; forms drawn alike.
