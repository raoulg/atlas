A value no name holds (one call's result handed straight to the call around it, `total(parse(text))`) is named by
the step that makes it: `#0`, `#1`, and so on. Each body now counts its own values from `#0`. Before, one count ran
over every function read, so a function's names depended on how many such values the functions read before it held.
Adding a function to another module, or reading a library one round deeper, renamed values in functions that had not
changed.

No picture: the page reads a `#` name as no name, and draws the same. What shows the change is the graph's JSON
(`atlas analyze`, the page's data), and everything that compares two readings of it. Take a package `shop` where
`orders.report` runs `print(total(parse(path.read_text())))`, and add a function `shout` to `shop/audit.py`, a module
read before `orders`:

```text
analyze --no-cache, shop, then shop with shout added to audit.py: the steps of shop.orders.report
  0.71.0 (2f8533e2)   parse → #0 → total      then      parse → #1 → total
  with #341           parse → #0 → total      then      parse → #0 → total
```

`atlas changes` reads a `#` name by the step that makes it. It says the same in both builds: `+ audit.shout`, and
nothing of `report`.

Release builds of the base (2f8533e2) and of this change, on Atlas at this change and on the 330 programs under
`engine/tests/pairs`:

| command | subjects | what differs |
| --- | --- | --- |
| `atlas analyze --no-cache`, the base against this change | Atlas and the 330 programs | 1,457 nodes in 50 subjects (1,348 of them in Atlas) as written; none once each function's `#N` is renumbered, and nothing outside the nodes |
| `atlas analyze --no-cache`, `--libraries 1` against `2`, each build | Atlas | 0.71.0 (2f8533e2): 1,209 nodes, 1,024 of them only in their `#N`; with #341: the other 185, none only in its `#N` |
| `tools/pictures.py compare`, the base against this change | `python/clean`, `rust/clean`, `collections/typescript/shortcut`, `choices/rust/clean` | nothing: 41 pictures, all the same |

With each body counting its own, one `#N` stands in several functions: in 50 of the subjects, among them each of the
four drawn (in the base only Atlas, whose parts each counted their own). Every `#N` a step is handed is made by an
earlier step of the same body: across Atlas and the 330 programs that holds for all 4,544 hands, so the page finds
each value in the frame its maker stands in, whatever the numbers in another function.
