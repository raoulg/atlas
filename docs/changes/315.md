In Atlas Studio the first wheel or two-finger move over the Atlas view zooms the picture. Before, a fresh window took no
wheel over the view until the page had been used (a click on `+`, say); the same wheel over Studio's file tree scrolled
it. The page now listens for the wheel on its document and hands to the zoom what is not on the picture itself, the
strips over it as before; a wheel over the code panel scrolls the panel.

WebKit hands a page in a frame a wheel only where that page listens for one, and in Studio's WKWebView a listener on
the picture alone did not count from the start. Playwright's wheel reaches the page past that machinery, which is why
#230's probes did not see it.

No picture: the gestures change, not what is drawn. What shows it is a debug Studio on the `built/python` pair, a fresh
window and no click in the view, wheeled with macOS scroll events; the page told Studio's status bar each wheel it
received. In Chromium and WebKit (Playwright) the strips still hand the wheel on and the code panel still scrolls.

| a fresh Studio window, then wheel over | before | after |
| --- | --- | --- |
| the picture | no wheel reaches the page | zooms in (k 1.40 → 1.65) |
| the legend | no wheel reaches the page | zooms out |
