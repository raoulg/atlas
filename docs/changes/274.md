Inside the engine a principle is a closed set of eleven, each with its id, what it asks and the rule that finds
where code disagrees, so a principle cannot be listed without its rule or checked without being listed. Its id is its
form outside the engine: the JSON of `atlas check`, its text, a decision such as `# atlas: ignore[changes] in place`
and what the MCP is handed. Nothing a user sees changes. `atlas check --all` and `atlas check --json`, built from
`next` before (f33f41c3) and with this change, print the same on Atlas, its fixture and each of the 50 pairs (260
findings, every principle among them), and on a pair given decisions in `.atlasignore` and in comments:

```text
what is compared, before and after                                  says              same
check --all, check --json: Atlas, fixture, 50 pairs                 260 findings      yes
check on a pair with decisions, one naming `chnages`                14 set aside      yes
MCP principles, explain, check (text, JSON, one principle, unknown)  11 answers        yes
```
