A folder a program gives a type of its own, whose method names each file in it, is read as the same folder written out
with bare paths. `Workbench::of(project).file("report.txt")` in Rust, `Workbench.of(project).file("report.txt")` in
TypeScript and a classmethod's `cls(project / ".made")` in Python drew `report.txt`, as if the file lay where the program
runs, or `{root}/report.txt`; they now draw `.made/report.txt`, fixed by the `main` that hands `.`, as
`made_dir(project).join("report.txt")` does. In Python, `cls(..)` in a classmethod is a call that builds its class, so
the route goes into its `__init__`.
