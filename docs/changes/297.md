What's New in Atlas Studio showed an empty window. Studio asked for the notes at the site's old address,
`raoulg.github.io/atlas`, which redirects to `atlas.pttrn.io` over plain http, and the window loads no page over http.
Studio now asks the site at its own address, over https, and counts an address as a page only when it answers 200
itself: a redirect sends Studio to the release on GitHub, in the browser, instead of to an empty window. The GitHub
release and the README link the notes at the same address.

What the two addresses answered on 29 October 2026, as Studio asks them:

```text
$ curl -sSI https://raoulg.github.io/atlas/releases/0.69.3/
HTTP/2 301
location: http://atlas.pttrn.io/releases/0.69.3/      a redirect, to http: the window stays empty

$ curl -sSI https://atlas.pttrn.io/releases/0.69.3/
HTTP/2 200                                            the page itself: the window shows it
```
