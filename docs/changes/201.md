`studio/build-app.sh` builds Atlas Studio with its own `atlas` inside and installs it in ~/Applications, to start from its
icon; started from the Finder it takes the login shell's PATH and reopens the last workspace. Every release and nightly
has a disk image of Studio for Apple silicon and Intel, its version Atlas's own, and `install-studio.sh` installs it
without the "Open Anyway" step a browser download needs. Windows has a setup program that installs Studio for the user
alone, and `install-studio.ps1` runs it without SmartScreen's question. Linux on x86_64 has a Debian package and an
AppImage, each with the matching `atlas` inside: `install-studio.sh` puts the AppImage in `~/.local/bin` and adds it to the
application menu, or with `ATLAS_STUDIO_PACKAGE=deb` installs the package. Neither platform's build is signed with a paid
identity. Linux on arm64 has no build, and Studio does not install its own updates on Linux: the install script runs again.
