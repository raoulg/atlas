`studio/build-app.sh` builds Atlas Studio with its own `atlas` inside and installs it in ~/Applications, to start from its
icon; started from the Finder it takes the login shell's PATH and reopens the last workspace. Every release and nightly
now has a disk image of Studio for Apple silicon and Intel, its version Atlas's own, and `install-studio.sh` installs it
without the "Open Anyway" step a browser download needs. Studio is signed ad hoc; Windows and Linux packages are to come.
