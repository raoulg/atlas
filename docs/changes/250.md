A path a library makes absolute (`std::path::absolute`) or writes without its `.` and `..` (`path_clean::clean`) is
the place it was handed. A note saved in `./data/../notes` and read from `notes/note.txt` drew two places, one of
them `note.txt in an unnamed folder`; it now draws one file between `save` and `show`. A loop of the program's own over
a path's parts stays what Atlas does not evaluate: the shortcut side still draws `File({folder.out}/note.txt)`. Atlas
drawn by itself writes its paths with `path-clean`, so the files its repository reads are `{dir}/{key}` below the
directory each caller names, where they were `{normal.out}`. Atlas Studio finds `atlas-code`, `claude` and `codex` on
the `PATH` with the `which` crate, and runs `uv` as the `PATH` finds it (`ATLAS_UV` where it is set).
