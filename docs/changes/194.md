Every build of Studio's installers, on macOS, Windows and Linux, ends by starting the `atlas-code` it carries the way Studio
does (`atlas-code serve` on a small repository, a free port, no browser) and fetching the page the window loads and the files
it lists (`studio/smoke-serve.sh`). The command line and the window run the same binary, so a repository opens to the same
page in the browser and in Studio on each platform. What the window then draws of it, in the platform's own web view, is not
checked by a test.
