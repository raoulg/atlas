A route that calls a step in a loop, where the step may write a place and then reads it (`show` fills the note for a
word with `+`, then prints it), changes what it found: a later round writes over what an earlier one read. Atlas drew
such a place between the steps, as if the route only made sure of it; it now stands on both sides, `from` and `into`,
as it already did when the same loop is written in one body (the pictures: `loop-calls-a-fill` before and after,
drawn by `tools/release_report.py`). The effect functor's law found it.

The effect functor, Yoneda (with effects belonging to the arrow), reach and gluing are now held by tests that compute
both routes of each law on graphs `proptest` draws (`engine/tests/arrows.rs`). Closing and Side of refinement are held
for every pair and plan (`engine/tests/plans.mjs`).
