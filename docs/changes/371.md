A file a method is handed is named by the method's class and its own name, `Repo.read.dir`, as a function's is named
by the function (`plot.out`) and a constructor's by its class (`Store.path`). `atlas changes` now reads that name as
the reader writes it, through one function, `model::owner`, where it read a method's by `read` alone. So a renamed
method, or a method of a renamed class, is one method, renamed, and its file one place, as for a function; it was a
method removed and one added, or under a renamed class a method changed, its file removed and added beside it. And a
method that hands on the path it is handed is the same when a caller comes to hand it one, as a function and a
constructor are: what a function is handed is no part of its own arrow. A rename also carries the type that holds a
renamed class's files (`Graph::rename`), so the page no longer draws the old type's group removed and the new one
added.
