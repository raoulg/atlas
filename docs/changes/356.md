In Python, `both: list[Level] = [first, second]` reads `first` and `second`; `Level` names the type of `both` and is no
value the body reads. Atlas read it as one: the function's uses held `signal.Level·Level`. It now reads an annotation as
Rust's `let both: Vec<Level>` and TypeScript's `const both: Level[]` are read, so a function's uses are the same with and
without the annotations of its locals. The page drew no difference (the fine plan left the name out); the graph shows it,
`Node::uses` of `_pair` in the locals pair (`engine/tests/pairs/locals/python/clean`):

```text
before  signal.Level·Level  signal.Level·second  signal.Level·first
after                       signal.Level·second  signal.Level·first
```
