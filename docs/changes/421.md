The packages view gathers the places one type holds into one group box. Before, a closed group was labelled with the
bare type name, so vectormesh's `EarlyStopping` group stood beside the type box `EarlyStopping`, and opening a group
stopped the page ("Cannot read properties of undefined (reading 'label')"), so the files written under `tmp/artefacts`
and `tmp/runs` could not be seen.

Now a closed group says how many places it stands for (`EarlyStopping · 3`), and an opened group shows its files as the
disk folds them: a directory stands in the group when every file it folds is the group's, and beside it otherwise
(`Cache` opens to `File(tmp/cache/) · 2`).
