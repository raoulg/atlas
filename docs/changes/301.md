Nothing drawn changes: the picture draws the place, which was right already. What changes is what the graph says to
whoever reads it, `atlas-code analyze` and the MCP: a touch's `what`. A path with a part the code leaves open was named
by its term (`~/data/{name}`), but a path written out in full was named by whatever its call held: a literal, an
expression, a parameter's name, or a literal of another part of the call. Three programs that write one log beside
their data files, one per language, named it three ways. Now `what` is the place itself, however the code spells it
(`./.made/log.txt` is `.made/log.txt`), and a folder is named as one.

```
$ atlas-code analyze -o g.json engine/tests/pairs/parents/<language>/clean    # the log's touch, the pair at eeca2256
            op              what, before                         what, after         artifact
python      open            shelf.log                            ~/data/shelf.log    ~/data/shelf.log
rust        write           shelf.log                            ~/data/shelf.log    ~/data/shelf.log
typescript  writeFileSync   join(dirname(source), "shelf.log")   ~/data/shelf.log    ~/data/shelf.log

$ atlas-code analyze -o g.json engine/tests/pairs/workbench/rust/clean       # bench.clear
rust        remove_dir_all  report.txt                           .made/              .made/
```
