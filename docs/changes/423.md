A torch model handed to a call, most often `print(model)`, drew as a second run of the model's `forward`: a loose step
with nothing going in or out, beside the real forward pass. Atlas took every callable value handed on as called by
whoever receives it, which is right for a function and a guess for an instance. Now an instance handed on is a value,
whether its class is a torch module or defines `__call__`; only calling it, `model(x)` or `model.forward(x)`, runs it.

Kind: drawn wrong, now right.
