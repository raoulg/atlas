The directory of a path the code builds of several parts went up too far or not at all. `Path("a/b").joinpath(name).parent`
was `a` rather than `a/b`; the directory of a path a caller hands (`source.parent`, `source.parent()`, `dirname(source)`)
stayed `{source}/..` once the caller handed `~/data/{name}`, a file of its own beside the data rather than in their
directory; and the directory of what the environment names (`Path(os.getenv("SHELF_DATA")).parent`) was a hole with no
name. Now the directory of a path is the path without its last part, a value written between two `/`s being one part, in
Python, Rust and TypeScript alike: a log written beside the data files rests in their directory. The parents pair
(`engine/tests/pairs/parents`) writes a log in the directory of the data file it reads:

```text
the log log(source) writes        clean (the path library's parent)   shortcut (the text cut at its last /)
Python, Rust, TypeScript
  before                          ~/data/{name}/../shelf.log          {log.folder}/shelf.log
  after                           ~/data/shelf.log                    {log.folder}/shelf.log

receivers pair, log(source: Path)
  before                          ~/data/{name}/../shelf.log          {}/shelf.log
                                  {$SHELF_DATA}/{name}/../shelf.log
  after                           ~/data/shelf.log                    {}/shelf.log
                                  {$SHELF_DATA}/shelf.log
```
