A function that lists a folder and calls itself on each folder it finds (`copy_tree(entry, target / entry.name)`) was
followed one call at a time, down to a depth limit: each level of `data/*/*/…` a place of its own (`File(data/) · 15`),
and at the limit a folder fourteen levels into a `{source}` no call hands, with what it writes in an unnamed
`into disk`. Now the recursion is followed to where it ends: every folder at any depth below what the first call
hands, `data/**`. The copy reads each file in any folder at any depth in `data/` and writes into any folder at any depth in `backup/`, the
same place as a walk with `rglob("*")` reads. The same in Python, Rust and TypeScript (the pair `trees`).

```text
example: engine/tests/pairs/trees/python/clean, route backup.main
  next (9cce2767)     copy_tree reads data/*/, data/*/*/, … thirteen levels, and {source}/*/…/*; writes backup/{name}/…/{name}
  with #325           copy_tree reads data/**/*; writes backup/**/{name}
on Atlas itself: the test helpers that copy a folder (aside, common, workspace_index), plans' list of every program
  and Environment.offered each name one place per walk: 38 → 9, 21 → 5, 20 → 4, 111 → 10 and 80 → 10 touches
```
