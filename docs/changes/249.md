The history (`atlas history`, `/history` beside `atlas serve`, Studio's history) reads the commits again while it is in
view, every few seconds and whenever it comes back into view, and redraws when git says something new. A push moves
`origin/main` onto the commit just pushed, a new commit or branch takes its row, and the working tree turns from clean
to changed, with no reload; the commits picked as A and B, the cursor and the scroll stay where they were.
