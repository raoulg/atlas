A night that measured slower used to need a second slow night before anything was said. Now a suspect night is
measured again in the same run: the last commit within the band and tonight's, interleaved on the same runner,
so that the runner's noise cancels. Not reproduced, it was the runner. Reproduced below ×1.5, it is commented on
the tracking issue with both commits and the numbers; from ×1.5, the range is bisected on the spot and an urgent
issue names the landing. Every Monday `next` is measured against the last release the same way, for creep no
single night shows, and the workflow bisects any range by hand (`mode: bisect`). `tools/perf.py release-bars`
gives every release's notes their numbers against the release before.
