An environment variable whose fallback is that same variable (`os.environ.get(name, os.environ["F"])`, handed `"F"`)
is the variable `$F` alone, as `os.environ.get("F", os.environ["F"])` written out already was: a value with itself to
fall back to is the value. Before, the lookup whose name a caller hands kept the fallback as a default of its own once
the name was said, so the two forms were two different terms. Nothing in the picture showed it, since both draw as the
file `$F` names; the law `paths::tests::a_lookup_commutes_with_what_is_handed` found it, and holds it now with the case
proptest shrank to.

Kind: drawn wrong, now right (a fact of the term; the picture draws the same).
