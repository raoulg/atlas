Picking a kind of route (`All Library`, `All CLI`, `All API`) draws the overview by package, of only the code those
routes reach. The packages, the types that cross between them, the libraries and the places are the overview's own,
less what no route of the kind runs: in the pair, the API routes never reach `cli`, `report` or `locations`, and of the
disk and the database they touch a part. Everything the overview does, it does here: a package opens into its modules,
classes and functions, shift-click puts a box in focus with the kind still picked, and the bar's path reads
`program › all API routes › package`. One route is read on its own page, picked from the list as before.

A function keeps the lines the whole program's picture draws of it: a file whose path a caller outside the kind hands
is drawn with that path.
