Atlas asked Python for doors where its root names none, and asked TypeScript and Rust nothing. A part is now asked for doors
wherever its manifest says it is meant to be imported: a Cargo package with a lib target, a `package.json` that is not
private (and names `main`, `module` or `exports`, or names no `bin`), a Python package with a build system or an
`__init__.py`. A library crate with nothing `pub`, or a package whose `package.json` points at nothing, is now
asked what a user may import. An app (a crate with only `main`, a private or `bin`-only `package.json`, a project of
scripts) has routes, not doors, and is asked nothing, also in Python.
