Opening a program with many functions that make a path whole for others (Atlas itself is one) took one to two minutes
on every start in Studio and `atlas serve`, also when the reading came from the cache: the time went into working out
what each step reads back and changes, not into reading. It now takes seconds. Nothing in the picture changes; on
Atlas's own graph the arrows are the same, byte for byte. A timing shows it:

```text
flow::of on Atlas's graph (3224 nodes, 13826 edges, --libraries 0)
  before   132.6 s   over 7 GB
  after      1.6 s   0.4 GB
```

(`flow::of` timed alone on the graph `atlas analyze` writes of Atlas at 2895d3ac. Studio
runs it twice a start, once for the local code and once with the libraries; the reading itself, from the cache, takes
0.13 s.)
