The overview of a program could stop with `Atlas could not draw this view` and an `UnsupportedConfigurationException`
from the layout: it did so whenever one package (or one part) only wrote to the world while the picture had a column of
types between packages. Such an overview now draws, its four columns as they are: what the packages read, the packages,
the types between them, what they write. Every view is laid out by one function, and a law test lays out overviews drawn
at random in node with the page's own layout.
