A class whose call runs a method a library names (torch's `Module` runs `forward`) is a route of its own, `Class · Head`:
its forward pass from input to output, each stage a step, the constructor no step of it. `atlas-code view <folder>`
opens on that route when the folder's scripts run one outermost module, the one that runs the others; `serve <folder>`
and the MCP `view` tool open the same way; otherwise the page opens as before. Two modules of one name carry the part of
their module that tells them apart (`01_kernels.Kernels`).

The shapes open closed in their rank families (`Float Tensor · 2D`). One button, `shapes`, opens every rank family of the
picture into its shapes, each axis in the name its signature gives it (`batch × hidden · h` for
`Float[Tensor, "batch {self.hidden}"]`), and closes them again; it shows where opening tells something. The input
carries the name the route gives it (`embed`).

A stage marked `@option("skip")` or `@option(axis="skip")` (vectormesh's `design.option`) titles the choice it runs under `option skip · if
self.config.skip`; the same stage under a bare `if` reads `only when self.config.skip`, and so does a script's choice that calls the stage. Under the route, the
configuration the module was built from is listed once, each field under the first stage that reads it, a field that
decides an option boxed.
