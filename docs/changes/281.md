Atlas's command is `atlas-code`, and the nightly's `atlas-code-nightly`: other tools (ariga's database toolkit,
MongoDB's Atlas CLI) install an `atlas`, and Atlas could not be installed beside them. `alias atlas=atlas-code` keeps
the short name. `install.sh`, `install.ps1` and `atlas update` remove an `atlas` that Atlas installed earlier, and
`brew upgrade` takes it away with the old version; the formula no longer excludes ariga's. The MCP server keeps its
name, `atlas`; an agent registered with `atlas mcp` is registered again with `atlas-code mcp`. The help says
"Atlas — your code's topology". Nothing in the picture changes; the install shows it:

```text
$ curl -fsSL https://raw.githubusercontent.com/raoulg/atlas/main/install.sh | sh
atlas-code installed in ~/.local/bin/atlas-code
removed the earlier ~/.local/bin/atlas; to keep the short name: alias atlas=atlas-code
```

Atlas's site is https://atlas.pttrn.io; `raoulg.github.io/atlas/` sends you there.
