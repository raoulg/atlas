A finding of `atlas check --json` carries `about`: the ids of the places, types and functions it is about, each with
its role (the sum and its variants, the steps that return or take it, the type a lens loses, ...). An agent reading a
finding no longer has to find names in its sentence. The MCP `check` tool gives the same data with `json: true`.
Nothing in the picture changes; the output shows it:

```json
{
  "principle": "sums",
  "node": "harvest.model.Fetched",
  "what": "Fetched (Reading | Outage) is handed on unopened: show and unreached take it",
  "about": [
    { "role": "sum", "id": "harvest.model.Fetched" },
    { "role": "variant", "id": "harvest.model.Reading" },
    { "role": "variant", "id": "harvest.model.Outage" },
    { "role": "returned_by", "id": "harvest.client.WeatherClient.latest" },
    { "role": "returned_by", "id": "harvest.harvester.Harvester.collect" },
    { "role": "taken_by", "id": "harvest.cli.show" },
    { "role": "taken_by", "id": "harvest.report.unreached" }
  ]
}
```

(`atlas check --json engine/tests/pairs/python/shortcut`, abridged.)
