Studio is not signed with a paid identity, so macOS and Windows block its first start when it comes from Homebrew or
from a disk image or setup program downloaded in a browser. The README's Atlas Studio install now says what to do
there and then: on macOS, System Settings › Privacy & Security › Open Anyway; on Windows, More info › Run anyway. It
used to send the reader to the install reference for this. Nothing in Atlas or Studio changes.
