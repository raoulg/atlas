The packages view is now drawn as a route's pictures are: from one fine plan of the code's functions, each with what its
own code takes, makes and touches, and the calls between them, closed by what the reader has open. The same oracle holds
it, so opening a package never brings a line its closed box did not draw.

What moved. A package that makes a type another package takes, and takes that type itself, now draws the line into it
too: `store` makes the `Shelf` that `report` shows and counts it itself (`count(shelf)`), so `Shelf → store` is drawn
beside `store → Shelf`; without it, opening `store` added the line. Each line carries its count, the functions it stands
for (`Shelf → report ×2`: `render` and `total`). A closed part draws what all its code touches and the types that cross
to another part, no longer what its routes reach; on Atlas itself the three parts now show the test code's fixture files
and the `Graph`, `Options` and `Flow` that `atlas-engine` hands `atlas-code`. An opened module shows its functions that
draw a line, data or call, where it showed its routes and the functions other packages call; a call to a class built
from its fields is the line to the type it makes, no call.
