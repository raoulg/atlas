Python's path classes (`Path`, `PurePath` and the rest of pathlib, `os.PathLike`) are known where ty finds them in
their library, in every place Atlas asks: where a place starts at a literal, what a library function's parameter is
handed, and what a call makes. A class of your own named `Path` is your own class: a function that takes one takes
your class, as it would one of any other name. Atlas reads a Python project's `ty.toml` and `pyproject.toml` through
the one reading of the repository, as it reads every other file of it (#239).

A function written in a body and called there by its name is read as a function: its parameter is what each call hands
it. A Rust closure a `let` keeps, a Python lambda a name keeps and a `def` inside a `def` now read the files their calls
name, where they read a hole named by the parameter. The closures pair (`engine/tests/pairs/closures`) reads a
project's settings through a function of the module on its clean side and through one written in the body on its
shortcut (the Rust side; the Python side reads `pyproject.toml` where Rust reads `Cargo.toml`, and the same holds):

```text
the files they read                    clean (a module's function)        shortcut (written in the body)
settings: text("knot.toml") or text(..)
  before                               {root}/knot.toml {root}/Cargo.toml  {root}/{name}
  after                                {root}/knot.toml {root}/Cargo.toml  {root}/knot.toml {root}/Cargo.toml
lock: text("knot.lock")
  before                               {root}/knot.lock                    {root}/{name}
  after                                {root}/knot.lock                    {root}/knot.lock
```

In the receivers pair (`engine/tests/pairs/receivers/python`), `walked(walk: Path)` takes the project's own dataclass
`Path`:

```text
atlas-code analyze engine/tests/pairs/receivers/python/clean -o clean.json
jq -c '.edges[] | select(.src == "shelf.walk.walked" and .kind == "takes") | .dst' clean.json
  before   (nothing: the annotation's `Path` was taken for pathlib's)
  after    "shelf.walk.Path"
```
