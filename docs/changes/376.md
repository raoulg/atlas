In Rust, `let mut kept = None; kept = Some(level); draw(kept)` now hands `draw` the `level` the assignment kept under
`kept`, as `let kept = Some(level); draw(kept)` does. The same holds when the `let` is a tuple pattern
(`let (mut kept, mut count) = (None, 0)`). Before, `kept` was read as another name for `None`, which holds no value, so
`draw` was handed nothing.

A name now stands for another only where that is a place the code holds: `self`, a name the body binds, or a constant
or a static of its module. A variant that holds no value, `None`, is none.

```text
example: engine/tests/pairs/assigned/rust, alone
  clean      let kept = Some(level);                   draw handed Level · kept
  shortcut   let mut kept = None; kept = Some(level);  before: draw handed nothing    now: draw handed Level · kept
```
