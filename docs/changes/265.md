A choice of more than 26 arms (a `match` over a large enum) gave two branches one letter: arm 26 was `2a` again, so
`→ see 2a` pointed at two steps and `choices` printed two branches as `a`. Branches past `z` are now lettered as a
spreadsheet names its columns, and the overrides of a step that is lettered already are set off by a dash, so that no
label names two branches. The route of a `match` of 30 arms, the first of which also calls a trait method two types
implement, before:

```
2a  arm0()   ·   prints   ·   when 0
2a  Shape.draw()   ·   one of 2   ·   when 0
  2aa  Circle.draw()   ·   prints
  2ab  Square.draw()   ·   prints
…
2z  arm25()   ·   prints   ·   when 25
2a  arm26()   ·   prints   ·   when 26
```

and after:

```
2a  arm0()   ·   prints   ·   when 0
2a  Shape.draw()   ·   one of 2   ·   when 0
  2a-a  Circle.draw()   ·   prints
  2a-b  Square.draw()   ·   prints
…
2z  arm25()   ·   prints   ·   when 25
2aa  arm26()   ·   prints   ·   when 26
```

`atlas check` said "something to ask" and "could not read" with one status, 1, and with findings it ended before
removing the temporary clone of a git URL. It now exits 0 with nothing to ask, 1 with something, and 2 when Atlas
could not do what was asked, as ruff and grep do; `atlas --help` names the three, and the clone is removed in each case:

```
$ atlas check engine/tests/pairs/choices/rust/clean; echo $?
0                     # before: 0
$ atlas check engine/tests/pairs/choices/rust/shortcut; echo $?
1                     # before: 1
$ atlas check /no/such/repository; echo $?
2                     # before: 1
```

A CI step that should report findings without failing, and fail when the check did not run, is
`atlas check || [ $? -eq 1 ]` (`docs/reference/ci.md`).
