From 0.70 the command is `atlas-code` (#281), since other tools install an `atlas` too. Until then `atlas` says so once a
day at a terminal, before its own output, with what needs the new name and the alias that keeps the short one. It stays
silent where the update check is silent: without a terminal, in CI, with `ATLAS_NO_UPDATE_CHECK=1`, and in `atlas mcp`
and `atlas analyze`.

```text
$ atlas check .
Note: from Atlas 0.70 this command is `atlas-code`, since other tools install an `atlas` too.
Scripts and MCP registrations that run `atlas` need the new name; `alias atlas=atlas-code` keeps the short one.
https://github.com/raoulg/atlas/issues/281
board · 0 questions
```
