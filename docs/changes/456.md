A step that returns what one of its calls gives draws that value going out through its frame, also where the
function's written return is another shape of the same array than the call's. `branch(..) -> Float[Tensor, "batch 16"]`
returning `projection(image)`, whose `forward` gives `Float[Tensor, "*lead {self.out}"]`, draws, opened, the line from
`Projection.forward`'s result to `branch`'s own point on its frame. Before, that result ended at no box, and the step's
output seemed to come from nowhere; the values handed in did arrive. The closed step draws as it did.

Python's type checker reads both shapes as `Tensor`, and the shape refines that type: what a body gives back is of a type
its signature gives as its language reads the type, so two shapes of one array type and dtype are one type there,
whichever is narrower. `return f()` and `x = f(); return x` now draw alike.

Kind: drawn wrong, now right.
