Before, the packages view drew a type only where the code both made and took that exact type. A function whose result
nothing else took, such as `card(shelf) -> Card`, or vectormesh's `forward` returning `Float[Tensor, "*lead {self.out_size}"]`,
drew what it took but no line to what it gave back, opened or closed.

Now every type of data a function makes or takes is a box of the overview, and the function draws its line to it. The
box stands in the smallest package that holds every function making or taking a type of its family, so a type only one
package uses stays inside that package, and the package borders still show only what crosses them.
