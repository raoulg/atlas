A large route is planned to a depth and each call beyond it stands for the image of its body. That image now takes
and gives what the body does when it is opened, so a route closed, a call beyond the cut and the view of all routes of
a kind draw what the code does. In the view of all exports, `news.read.headlines` builds a `Feed` and calls
`feed.lines()`, whose `self.read()` runs `Cached.read`. Before, it took a `Cached` from outside, as if another object
than the feed were read. Now it takes none: the feed is made inside the route.

The object a method runs on is one value, whichever class the method that takes it is written in: a base the method
resolution order reaches, `super().read()`, `Source.read(self)`. In each exported class (`ReadingStore`, `Kennisbank`,
`Ledger`, `Plot`), each door now counts its instance as often as its body uses it. A command whose `main` parses its
command line counts, with the entry closed, a line from the command line for each value the parse made that a step
takes. An override in a call into a family takes no value where the call hands it none: `Exporter.write(records, ..)`
with records of a generic type no longer draws a `Reading` from outside, and an override takes what its body uses of
the caller's value of a parameter it is handed: `ReportExporter.write` takes the `Report` it writes.

One law holds it on every pair (`every_kind_view_is_the_union_of_its_routes_closed`): each route's box, planned at the
cut, against the image of its finest plan. It found 21 routes that differed; none differs now.
