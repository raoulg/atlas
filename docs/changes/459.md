A focus on a module drew every type of a library the module touches one type of, each joined to the rest of the code,
with the module somewhere among them. It now keeps the types its own functions take or give, the ones it takes on the
left and the ones it gives on the right, and of the rest only the lines that meet it: `4D → fold → 3D`.
