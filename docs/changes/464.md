The overview opens at its coarsest. A library is one box, `torch · 13 types`, and a click opens it into the types the
program uses of it. The places of the world stand in their kind: the files a program writes are `Disk · 6`, and where it
reads the disk as well, `from Disk · 22` on the left and `into Disk · 5` on the right. A click opens a kind into a frame
around its places, each as it stood (a folder, the files a type keeps); the frame's title, or the chip in the state bar,
closes it again. A focus keeps the types of its own signature open, and a route draws its places as they are. An agent
opens a library with `open.libraries` and a kind with `open.places` in a view.
