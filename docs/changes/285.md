Three calls the Rust reader did not follow now run what Rust runs (#285, #207, #220). A unit struct named as a value is
a value of it, built there: a method called on it, on the name (`Plain.show(heading)`) or on a local bound to it (`let
words = Words; words.parse(text)`), runs its type's method, where the route drew no step at all. A call through the
trait that hands it the value first (`Language::parse(&Words, text)`) is the same call, and runs `Words.parse` rather
than the trait's method with every implementation as its alternatives. A trait is below its supertraits (`trait Block:
Named`): a `&dyn Block` asked its `name()` may run the `name` of each type that implements `Block`. And a call stands
among values: in a crate named `clash`, `clash()` calls the function `clash`, no longer the crate's module, so what it
writes reaches the route. The steps each draws:

```text
atlas analyze engine/tests/pairs/built/rust/shortcut -o g.json      # notes.report
  before   []
  after    [notes.Plain.name, notes.Plain, notes.Block.show on notes.Plain]

atlas analyze engine/tests/pairs/built/rust/clean -o g.json         # notes.report
  before   [notes.Block.show]
  after    [notes.Named.name on notes.Block, notes.Block.show]

atlas analyze engine/tests/laws/dispatch -o g.json                  # dispatch.words, dispatch.words_through_the_trait
  before   [dispatch.Words]                 [dispatch.Words, dispatch.Language.parse]
  after    [dispatch.Words, dispatch.Words.parse]   (both)

atlas analyze engine/tests/rust/clash -o g.json                     # clash.main
  before   [clash, clash.other]
  after    [clash.clash, clash.other]
```
