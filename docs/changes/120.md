When the code breaks a principle on purpose, the author writes the decision down beside it, after the language's line
comment (`# atlas: ignore[changes] in place for the frame rate`), or for whole paths in a `.atlasignore` at the top of
the repository, each with its reason. `atlas check` no longer asks again: what a decision answers is set aside and
counted beside the open questions, `--all` lists it with the decision, and `--json` keeps it with `aside`. A decision
that sets nothing aside, gives no reason or names a principle that is none is asked about, so the file does not outlive
the code. Nothing in the picture changes; the output shows it:

```text
────────────────────────────────────────────────────────────
12 questions, 4 set aside
           board
  changes     12
  nothing to ask: doors, sums, overrides, places, gives, choices, nothing, layers, lens, prophecy

2 decisions set nothing aside

  .atlasignore:3  src/gone/**  # removed long ago
    ? It covers no finding: is the decision still needed?

  .atlasignore:4  src/board/core.py  gives
    ? It gives no reason: why does the code stand as it does?
```

(`atlas check` of `engine/tests/pairs/changes/python/shortcut` with a decision on `reset` and this `.atlasignore`:
`src/board/edits.py  changes  # edits are in place for now`, `src/gone/**  # removed long ago`,
`src/board/core.py  gives`. Before, the same program asked all 16 questions.)
