Nothing a user sees changes. Inside the engine a route that `atlas changes` lists as added, removed or changed carries
the same three verdicts as the nodes and places of a diff, and the signs `+ - ~` of its text come from one place. The
JSON still says `"added"`, `"removed"` and `"changed"`.

No picture: what shows it is the output, the same bytes from the build before (f33f41c3) and after, each run with
`--no-cache` on Atlas's own repository:

| command | before and after |
| --- | --- |
| `atlas analyze .` | identical, 12.8 MB of JSON |
| `atlas analyze` of `engine/tests/fixture` and `engine/tests/fixture-ts` | identical |
| `atlas changes HEAD~5`, text and `--json` | identical: 15 routes added, 2 removed, 568 changed |
| `atlas changes HEAD~60..HEAD`, text and `--json` | identical: 98 routes added, 4 removed, 586 changed |
