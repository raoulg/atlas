A node whose own arrows differ between the two readings is marked changed on the page. `atlas changes` said what it
was only where a route reaches it in both readings, or on no route. A node a route reaches in one reading only (a type
that gains an arrow because the route now calls a new method) was listed as `+ step` with nothing of what it was.

Now every node the page marks changed is listed `~ step` with what it was wherever a route reaches it, in one reading or
both, beside its `+ step` or `- step`.

Kind: drawn wrong, now right. Nothing to draw: the page already marks the node; the list now agrees.
