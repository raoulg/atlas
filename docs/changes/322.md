A push to `next` ran the whole suite on three platforms, and built Studio when it touched `studio/`; each push cancelled
the run before it, and the nightly built only a head whose own run was green, so a busy day left `next` without a
nightly. Now a push to `next` runs nothing. The nightly, at 03:30 or started by hand, tests exactly the commit it is
about to build on Linux, macOS and Windows, and builds and publishes only once those tests pass; a failure is a red
nightly in the morning, and the last good one stays. `main` and pull requests keep their CI. Nothing in the picture
changes; the nightly's jobs:

```text
before   decide (next moved? ci of its head green?) → build, studio → publish → tap, site → prune
after    decide (next moved?) → test (ci.yml on that commit) → build, studio → publish → tap, site → prune
```
