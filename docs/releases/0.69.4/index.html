What changed in Atlas 0.69.4

Atlas 0.69.4 makes What's New in Atlas Studio show the release's notes again. What Atlas reads, draws and checks is the same as in 0.69.3.

only in the release beforeonly in 0.69.4its text changed, its arrow not

What's New shows the notes

Studio showed a release's notes from raoulg.github.io/atlas, which redirects to the site's own address, atlas.pttrn.io, and for a while redirected there over plain http. Studio's window loads no page over http, so What's New stayed empty. Studio now asks the site at its own address, over https, and takes an address as a page only when it answers with the page itself; any other answer, a redirect too, opens the release on GitHub in the browser. The GitHub release and the README link the notes at the same address.
