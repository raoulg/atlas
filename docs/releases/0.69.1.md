Atlas 0.69.1 opens a large program in seconds, also when Studio has read it before.

## A large program opens in seconds, warm or cold

Opening a program with many functions that make a path whole for others (Atlas itself is one) took one
to two minutes on every start in Studio and `atlas serve`, also when the reading came from the cache: the
time went into working out what each step reads back and changes, not into reading. Each step is now
worked out once for what the calls above it change in it. Nothing in the picture changes; on Atlas's own
graph the arrows are the same, byte for byte.

Bars: 0.69.0 = 132.6 s; 0.69.1 = 1.6 s | Working out the arrows of Atlas's own graph (3224 functions and places, without libraries); Studio does this twice a start. Memory went from over 7 GB to 0.4 GB.
