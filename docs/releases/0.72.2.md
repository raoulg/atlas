Atlas Studio 0.72.2 says when a newer build is installed while it runs, and restarts on it. What Atlas reads, draws and
checks is the same as in 0.72.1.

## Studio says when a newer build waits for a restart

Kind: wrong

When Studio's app was replaced while it ran (by `brew upgrade`, or the install script), the window kept running the
build it started as, yet said it was up to date and showed the new build's notes. Now Studio keeps the build it started
as for as long as it runs, and when a newer one is installed under it, it says so, with that release's notes and a
Restart button; the status bar shows both.

Compare: releases/0.72.2/img/426-installed.png = 0.72.2: started as 0.72.0, with 0.72.1 installed under it: the notes of 0.72.1, Restart, and `↻ Studio 0.72.1` beside `Atlas Studio 0.72.0`
