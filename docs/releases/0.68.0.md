Atlas 0.68 comes as a desktop app, reads a repository a hundred times faster the second time, and
draws what your code does more faithfully: which way data goes, which figures a program makes, and
how it can fail.

## Atlas Studio: Atlas as an app

- 🦀 A desktop app for macOS and Windows, built with Tauri around Atlas's own Rust engine.
- Your workspaces remembered: ⌘O (Ctrl+O on Windows), or File › Open Recent.
- Your files as Atlas reads them: a file Atlas traced opens where the picture has it.
- Markdown, HTML and PDF previewed beside the picture.
- Your own terminal, in the workspace.
- Studio tells you when a new version is out, and shows what changed.

[Download Atlas Studio](https://github.com/raoulg/atlas/releases/latest), or install it from a terminal.
On macOS:

```
sh -c "$(curl -fsSL https://raw.githubusercontent.com/raoulg/atlas/main/install-studio.sh)"
```

On Windows, in PowerShell:

```
irm https://raw.githubusercontent.com/raoulg/atlas/main/install-studio.ps1 | iex
```

## A hundred times faster, the second time

Atlas keeps an index of what it read of a repository, and reads again only what changed. While it
reads, a bar shows how far it is, first the code and then its libraries, each estimated from how
long the last readings took.

Bars: The first time = 19.8 s; Every time after = 0.17 s | About 115 times faster: Atlas reading its own repository, release build, median of three rounds, the same graph each time (`tools/bench_workspace_index.py`).

## Zoom in, and nothing else moves

Open a box to see inside it: the rest of the picture stays exactly as it was. Every picture is the

## When the code is right as it is

Sometimes code breaks a principle on purpose. Say so beside it, with your reason, and `atlas check`
stops asking: what you answered is set aside and counted, never hidden. A decision that no longer
answers anything is asked about in turn.

## Why you can trust the picture

`atlas check` now asks only what each of its rules claims, so a question is worth reading.

And Atlas holds itself to its own mathematics. Each principle it follows is a law, and where it can,
Atlas makes the law true by construction: one function that every picture uses keeps it, and that
function is tested. Where a law cannot be guaranteed that way, it is tested from both sides: 23 of
the 31 notions of Atlas's mathematics are held by tests that compute both routes, on every opening
of small programs and on graphs drawn at random, or that tell a clean program from its shortcut.
11 of them are also asked every night of real code bases, at places drawn at random within a time
budget; a place that breaks comes back with its seed. What the picture shows is what the code does.
