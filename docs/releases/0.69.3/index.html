What changed in Atlas 0.69.3

Atlas 0.69.3 says that its command becomes atlas-code in 0.70. What Atlas reads, draws and checks is the same as in 0.69.2.

only in the release beforeonly in 0.69.3its text changed, its arrow not

The command becomes atlas-code

Other tools install a command atlas too (ariga's database toolkit, MongoDB's Atlas CLI), so Atlas cannot be installed beside them. From 0.70 the command is atlas-code, as its Homebrew package already is; alias atlas=atlas-code keeps the short name. Until then atlas says so once a day at a terminal. Scripts and MCP registrations that run atlas need the new name when 0.70 is out; atlas update and brew upgrade move the command itself.
