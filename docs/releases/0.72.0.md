Atlas 0.72.0 reads a PyTorch model the way its author writes it: a submodule that is called runs its `forward`, and
every value between two steps keeps the shape its jaxtyping annotation gives it. A model's forward pass draws as a
chain of shapes, from its inputs to its logits. The overview draws what each function gives back, and leaves the
program's tests out. A path built by helper functions is the whole path.

## A PyTorch model draws its forward pass as a chain of shapes

Kind: wrong

A model that calls its submodules, `self.projection(x)` and `model(x)`, drew its forward pass as one step that leads
nowhere, to values without a shape. Now calling a module runs its `forward`, and every value between two steps keeps
the shape its jaxtyping annotation declares. Printing or saving a model hands it on as a value and runs nothing.

Compare: releases/0.72.0/img/forward-0.71.png = 0.71: `model(dino, resnet)` is one dashed step to `logits`, and no value has a shape; releases/0.72.0/img/forward-0.72-in.png = 0.72, from the inputs to the join: batch 384 and batch 512 through `Projection.forward` to batch 128 each; releases/0.72.0/img/forward-0.72-out.png = 0.72, from the join to the logits: batch 256 through `NeuralNet.forward` to batch 47. Beside each step stands the shape its library declares, `*lead {self.out_size}`

Diagram: releases/0.72.0/img/forward.svg | Decided from principle (#422, #423): calling a module is calling its forward, and handing it on is not.

Issues: #422, #423

## The overview draws what each function gives back

Kind: wrong

The packages view drew a type only where the code both made and took it. A function whose result no other function
took, such as `card(shelf) -> Card`, or a model's `forward` that returns `Float[Tensor, "*lead {self.out_size}"]`, drew
what it took and no line to what it gave back. Now every type a function makes or takes is a box of the overview,
in the smallest package that holds all its makers and takers.

Compare: changes/419-before.png = 0.71: `card` takes the shelf and gives nothing; changes/419-after.png = 0.72: `card` gives a `Card`

Issues: #419

## A path built through helpers is the whole path

Kind: wrong

A path that each folder of it names with a helper function of its own was followed only so deep, so the archive's
stand-up notes were written to `{monthDir.folder}/11/2/meetings/standup.md`, the folder three helpers down left as a
hole. Now each function's return is read once, as a term of its parameters, and the notes are written to
`~/archive/2026/11/2/meetings/standup.md`, in Python, Rust and TypeScript alike. Reading Atlas itself got slightly
faster for it (9.8 s to 9.2 s, cold).

Compare: changes/396-before.png = 0.71: a folder left as a hole three helpers down; changes/396-after.png = 0.72: the whole path, `~/archive/2026/11/2/meetings/standup.md`

Issues: #396

## A tensor of any rank says so

Kind: wrong

A shape written as `Float[Tensor, "..."]`, which promises no axis, was drawn raw. It now reads `Float Tensor · any
rank`, as the shapes of a known rank read `Float Tensor · 2D`.

Compare: changes/420-before.png = 0.71: `encoders` draws none of its tensors; changes/420-after.png = 0.72: what `Encoder.encode` gives reads `Float Tensor · any rank`

Issues: #420

## A group of files opens, and says how many it holds

Kind: wrong

The places one type holds are gathered in one group box. Opening the group stopped the page, and the closed group
read like the type itself. A closed group now says how many places it stands for (`EarlyStopping · 3`), and opens to
its files as the disk folds them.

Compare: releases/0.72.0/img/421-before.png = 0.71: opening the group `Cache` stops the page; changes/421-after.png = 0.72: `Cache` opened, `File(tmp/cache/) · 2`

Issues: #421

## The overview shows your program, not its tests

Kind: ui

The overview drew all the code, tests included: a test's fixture file and the test's own types stood beside the
files the program reads. It now draws the program alone, without Rust's `#[test]` and `tests/`, pytest's `test_*.py`
and `conftest.py`, or a `*.test.ts`. The chip `without test code ✕` above the picture says so, and one click on it
draws the tests again.

Compare: changes/400-before.png = 0.71: the shelf with its pytest file and the fixture only the test reads; changes/400-after.png = 0.72: `store` opens to `disk` alone, which reads `shelf.csv`
